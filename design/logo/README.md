Reference artwork for the Playground mark. Its palette predates the app's tokens.

Shipped assets live in `apps/web/public/` and use the app's tokens (`app/app.css`): ink `#1c2430`, card white, canvas `#e8eaee`, faint ink `#8b93a3`, and the one accent `#2a5cff` on the lifted tile.

- `favicon.svg`: ink tile. `apple-touch-icon.png` is the same mark, full-bleed at 180px.
- `logo.svg`: transparent, for light backgrounds.
- `og.png` / `og.mp4`: link-preview card and Live deck loop (1200×630), generated by `bun run --cwd apps/web og`.
